# Candour

Software that's genuinely useful, honestly priced, and transparently run.

Candour is (for now) an unincorporated brand governed by a public constitution — a pledge with a published change history rather than a legal instrument, and we say so plainly. Start with [`constitution.md`](constitution.md). The roles that run the company are in [`roles/`](roles/); how ideas become products is in [`CLAUDE.md`](CLAUDE.md).

Our numbers — costs, margins, pay, surplus — will be published here as they come to exist. If you find a way to game our rules that we haven't listed in Article 9, tell us: we've committed to adding it rather than using it.
